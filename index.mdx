Welcome to the VOLLEY OSA (Open Systems Architecture) documentation. VOLLEY OSA v0.1 is a MOSA-aligned Interface Control Document (ICD) that specifies the REST and asynchronous API interfaces you need to integrate non-kinetic payload modules into the VOLLEY platform. Whether you are registering a new payload, dispatching commands, or consuming real-time telemetry streams, these docs give you everything required to build a compliant, interoperable integration from day one.

## Get Up and Running

<Steps>
  <Step title="Obtain API Credentials">
    Request access and receive your API key from the VOLLEY OSA platform.
  </Step>
  <Step title="Register Your Payload">
    Use POST /payloads to register your payload module and receive a payload ID.
  </Step>
  <Step title="Send Commands">
    Dispatch commands to your payload using POST /payloads/{id}/commands.
  </Step>
  <Step title="Stream Telemetry">
    Subscribe to the payload.telemetry AsyncAPI channel for real-time data.
  </Step>
</Steps>
